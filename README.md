# Конвертер азбуки Морзе

Веб-приложение для автоматической конвертации текста в код Морзе и обратно.

## Описание проекта

Это HTTP-сервер на Go, который позволяет загружать файлы с текстом или кодом Морзе и автоматически конвертировать их в противоположный формат. Сервер автоматически определяет тип входных данных (текст или код Морзе) и выполняет соответствующую конвертацию.

## Возможности

- ✅ Автоматическое определение типа входных данных (текст или код Морзе)
- ✅ Конвертация текста в код Морзе
- ✅ Конвертация кода Морзе в текст
- ✅ Поддержка русского алфавита
- ✅ Веб-интерфейс для загрузки файлов
- ✅ Сохранение результатов конвертации в локальные файлы

## Установка и запуск

### Требования

- Go 1.24.0 или выше

### Запуск сервера

1. Клонируйте репозиторий или перейдите в директорию проекта:
```bash
cd go1fl-sprint6-final-tpl-main
```

2. Установите зависимости:
```bash
go mod download
```

3. Запустите сервер:
```bash
go run ./cmd/main.go
```

Или скомпилируйте и запустите:
```bash
go build -o server.exe ./cmd/main.go
./server.exe
```

Сервер запустится на порту **8080**.

## Использование

### 1. Откройте веб-интерфейс

Откройте в браузере:
```
http://localhost:8080
```

Вы увидите HTML-форму для загрузки файлов.

### 2. Загрузите файл

- Нажмите кнопку "Choose File" и выберите файл с текстом или кодом Морзе
- Нажмите кнопку "upload"

### 3. Получите результат

- Результат конвертации отобразится в браузере
- Файл с результатом будет сохранен в корневой директории проекта с именем, основанным на текущем времени

## Тестовые файлы

В проекте есть два тестовых файла:

- **test** - содержит код Морзе: `.--. .-. .. .-- . -` (что означает "ПРИВЕТ")
- **test12** - содержит текст: `Привет`

Вы можете использовать эти файлы для проверки работы сервера.

## API Endpoints

### GET /

Возвращает HTML-форму для загрузки файлов.

**Ответ:** HTML-страница с формой

### POST /upload

Обрабатывает загруженный файл и конвертирует его содержимое.

**Параметры:**
- `myFile` (multipart/form-data) - файл для конвертации

**Ответ:**
- Успех (200): Текст с результатом конвертации
- Ошибка (500): Сообщение об ошибке

## Технические детали

### Автоопределение типа данных

Сервис автоматически определяет тип входных данных по следующим правилам:
- Если строка содержит только точки (`.`), тире (`-`), пробелы и символы новой строки, и содержит хотя бы один символ точки или тире - это код Морзе
- В противном случае - это обычный текст

### Настройки сервера

- **Порт:** 8080
- **ReadTimeout:** 5 секунд
- **WriteTimeout:** 10 секунд
- **IdleTimeout:** 15 секунд

### Формат кода Морзе

Код Морзе использует:
- Точку (`.`) для короткого сигнала
- Тире (`-`) для длинного сигнала
- Пробел для разделения символов
- Три пробела для разделения слов

## Разработка

### Структура пакетов

- **cmd/main.go** - точка входа, создает логгер и запускает сервер
- **internal/server** - настройка HTTP-сервера и роутера
- **internal/handlers** - обработка HTTP-запросов
- **internal/service** - бизнес-логика автоопределения и конвертации
- **pkg/morse** - функции конвертации текста в код Морзе и обратно

### Добавление новых функций

Для расширения функциональности:

1. Добавьте новую логику в `internal/service/service.go`
2. Создайте новый хендлер в `internal/handlers/handlers.go`
3. Зарегистрируйте хендлер в `internal/server/server.go`
